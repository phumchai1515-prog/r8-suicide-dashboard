# Dashboard ตัวชี้วัดการฆ่าตัวตายและพยายามฆ่าตัวตาย — เขตสุขภาพที่ 8

ระบบรายงานตัวชี้วัดสุขภาพจิต ปีงบประมาณ 2569 ครอบคลุม 7 จังหวัด:
เลย หนองบัวลำภู อุดรธานี หนองคาย บึงกาฬ สกลนคร นครพนม

## ตัวชี้วัด

| ตัวชี้วัด | เป้าหมาย |
|---|---|
| 1. อัตราการฆ่าตัวตายสำเร็จ | ไม่เกิน 10 ต่อแสนประชากร |
| 2. ผู้พยายามฆ่าตัวตายเข้าถึงบริการ = 100 × (ผู้พยายามฯ 506S ÷ ผู้มารับบริการ HDC) เพดานไม่เกินร้อยละ 100 | ไม่น้อยกว่าร้อยละ 70 |
| ตัวชี้วัดรอง: ได้รับการตรวจประเมินจิตเวช (ข้อ 7.2 แบบ 506S) | — |

## โครงสร้างโปรเจกต์

```
etl/parse.py        สคริปต์แปลงข้อมูลดิบ → docs/data.json (สรุปรวมเท่านั้น)
etl/test_parse.py   ชุดทดสอบ ETL
data/raw/           ไฟล์ข้อมูลดิบ (ไม่ commit — มีข้อมูลรายบุคคล)
docs/               เว็บแอพ Dashboard (เผยแพร่ผ่าน GitHub Pages)
```

## การอัปเดตข้อมูล (เมื่อได้ไฟล์รายงานใหม่)

1. วางไฟล์รายงาน 506S (.xls), ไฟล์ HDC export (.xlsx) และไฟล์ประชากร (.xlsx) ใน `data/raw/`
2. ถ้ามีไฟล์/ช่วงเวลาใหม่ ให้แก้ `CASE_FILES`, `HDC_FILE`, `FISCAL_MONTHS`, `HDC_MONTH_KEYS`, `MONTH_DAYS`, `PERIOD_END` ใน `etl/parse.py`
3. รัน:

```bash
python3 etl/parse.py      # สร้าง docs/data.json ใหม่
python3 etl/test_parse.py # ตรวจสอบความถูกต้อง
```

4. commit และ push — GitHub Pages จะอัปเดตอัตโนมัติ

ต้องมี Python 3.9+ และ `openpyxl` (`pip3 install openpyxl`)

## ความปลอดภัยของข้อมูล

- ข้อมูลดิบเป็นรายงานรายบุคคล (รง.506S) มีข้อมูลส่วนบุคคล — ถูกกันไม่ให้ commit ผ่าน `.gitignore`
- `docs/data.json` ที่เผยแพร่มีเฉพาะยอดสรุปรวมราย จังหวัด × เดือน × กลุ่มอายุ(หยาบ) × เพศ × วิธีการ เท่านั้น
- ETL มี validation ปฏิเสธจังหวัด/เดือน/ผลการกระทำที่ไม่รู้จัก และตรวจยอดรวมต้องตรงกับต้นฉบับ

## แหล่งข้อมูล

- รายงานเฝ้าระวังการทำร้ายตนเอง (รง.506S) 1 ต.ค. 2568 – 9 ก.ค. 2569
- ข้อมูลประชากรกลางปี 2568 กองยุทธศาสตร์และแผนงาน กระทรวงสาธารณสุข

## ข้อจำกัด

- ข้อมูลปีงบประมาณ 2569 ยังไม่ครบปี — ค่า "คาดการณ์ทั้งปี" คำนวณแบบ annualized
- จำนวนเคสจากระบบรายงานอาจต่ำกว่าจำนวนจริง (under-reporting)
